# Pokyny pre agenta, ktorý píše recepty
- Typy: `src/data/types.ts` (Recept). Zoznam dostupných surovín: `docs/zoznam-surovin.txt` (id | názov | skupina | gramy na kus). Používaj LEN tieto id. Ak ti surovina chýba, pridaj ju do NOVÉHO súboru `src/data/suroviny/extra-<tvoj-nazov>.ts` (`export const surovinyExtra<Nazov>: Surovina[] = [...]`, `odhad: true`, `zdrojNutr: 'typická hodnota (odhad)'`, id unikátne – skontroluj grep-om) – ale najprv hľadaj existujúcu.
- Súbor s receptami: `src/data/recepty/<tvoj-nazov>.ts` → `import type { Recept } from '../types'; export const receptyXyz: Recept[] = [ ... ];`
- Recept píš VLASTNÝMI slovami, uvariteľne: reálne pomery (porcie = počet dospelých porcií, typicky 4 alebo 2), množstvá v g/ml/ks/lyzica/lyzicka (soľ, korenie, olej v lyžiciach či gramoch – malé množstvá), reálne časy a teploty (°C), postup 4–8 krokov, bezpečnosť (mäso prepečené, vajcia, ryža ochladená). Slovenčina s diakritikou. Žiadne vymyslené zdravotné tvrdenia v texte receptu (žiadne „lieči“, „detoxikuje“); poznámky pre deti len praktické (napr. nerozdrvené orechy a celé hrozno do 4 r. nedávať, soľ šetriť).
- `nevyhnutna: true` pri surovine, bez ktorej sa jedlo nedá urobiť (hlavná zložka); `volitelna: true` pri tých, čo sa dajú vynechať (bylinky, posyp, prílohy); `alternativy` = id surovín, ktoré ju zmysluplne nahradia. Každý recept: aspoň 1 `nevyhnutna`, 1–3 `upravy` (typ 'pridat': napr. hrsť špenátu/semienka; typ 'vymenit': z = id suroviny v recepte, na = id inej suroviny).
- tagy z množiny: detske, rychle, do-krabicky, lacne, bezmasite, bez-peciva, bezlepkove (len ak naozaj bez lepku – test to kontroluje), vegansky, vyvarene-z-zvyskov, na-viac-dni, sladke. `bezmasite` = bez mäsa aj rýb. `vyprazane: true` iba ak sa jedlo smaží vo veľkom množstve oleja (rezne, hranolky); pečené v rúre = nie. `klasika: true` pre tradičné múčne/ťažké jedlá (zároveň ich rob verne, nie „zdravšie“); `lepsiaVerzia` nechaj `[]`.
- `ilustracia`: jedno emoji. Id receptu: kebab-case bez diakritiky, unikátne (pred koncom `grep -rhoE "id: '[a-z0-9-]+'" src/data/recepty | sort | uniq -d`).
- Po napísaní spusti `npx vitest run tests/data.test.ts` a oprav všetky chyby (neznáme id, duplicity, nesúlad tagov). Potom si recepty sám adversariálne prečítaj (pomery, časy, chýbajúce kroky, bezpečnosť) a oprav. Žiadny git. Vráť max 5 riadkov (počet receptov, súbory, čo si opravil).
