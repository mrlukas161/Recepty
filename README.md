# Recepty

Rodinná mobilná appka (PWA): čo variť, keď chceme menej múky, cukru, údenín a vyprážaného — náhrady, diéty s popisom, hodnotenie jedál podľa výskumov, jedálniček, nákupný zoznam a ruleta.

**Appka:** https://mrlukas161.github.io/Recepty/ (v Chrome na Androide: ⋮ → *Pridať na plochu* / *Inštalovať aplikáciu*)

> Nie je to lekárska rada. Skóre zdravosti je orientačná heuristika založená na zdrojoch uvedených v appke.
